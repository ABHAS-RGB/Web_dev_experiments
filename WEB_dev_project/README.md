GenderSense is a web-based platform designed to promote awareness about gender equality and challenge stereotypes. In today's world, where gender biases still affect many aspects of life, this project aims to educate users through interactive content, helping create a more inclusive society where everyone feels valued regardless of their gender identity.

The platform features several key sections. The home page welcomes visitors with an overview of gender sensitization and provides navigation to all areas. The About section explains core concepts, our mission to promote equality, and highlights three main pillars: Education, Awareness, and Action. The Resources page offers educational materials on gender concepts and workplace equality. There's also a Glossary for key terminology, a standalone Quiz to test knowledge on these topics, and a Contact page for support.

Technically, I built this using HTML5 for structure, CSS3 for styling and responsive design, and JavaScript for interactivity. I incorporated Google Fonts for a modern look and included a simple chatbot in the logic.js file that answers common questions about gender sensitization with predefined responses.
